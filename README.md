# Финансовый анализатор «Мои Деньги»

Удобное консольное приложение на Python для анализа личных финансов. Программа обрабатывает банковские выписки в формате Excel, позволяя отслеживать траты, проверять курсы валют и анализировать кешбэк.

## Основные возможности

*   **Главная (Events):** Сводка курсов валют (USD, EUR), котировки акций и топ категорий трат за месяц.
*   **Кешбэк (Services):** Расчет накопленного кешбэка по всем категориям за выбранный месяц и год.
*   **Отчеты (Reports):** Детальный анализ трат по конкретной категории за 3 месяца. 
    *   *Фишка:* Использование декоратора для автоматического сохранения отчета в `.json` файл.

## Зависимости и файл requirements.txt

Для работы приложения необходимы внешние библиотеки (Pandas, Openpyxl и др.). Все они перечислены в файле **`requirements.txt`**. 

**`requirements.txt`** — это стандартный файл в Python-разработке. Он служит «инструкцией» для системы: какие именно инструменты нужно скачать, чтобы твой код запустился на другом компьютере.

### Как установить все зависимости:
Откройте терминал в корне проекта и введите:
```bash
pip install -r requirements.txt
